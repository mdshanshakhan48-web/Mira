# MiraInstall (pehli baar):
pip install myra-ai-assistant
Isme Windows aur Python 3.11 (64-bit) chahiye. Ye python --version se check kar sakte ho.

Update (naya version):
pip install --upgrade myra-ai-assistant
Ya agar myra-upgrade command available hai to:
myra-upgrade

Chalane ke liye:
myra

Windows startup (PC start hone par background mein chale):
myra-install
Isko hatane ke liye: myra-uninstall. Ye ab bhi installed hai ya nahi, ye dekhne ke liye: myra status.

Agar pip na mile:
python -m pip install --upgrade myra-ai-assistant

Pura hata dena:
pip uninstall myra-ai-assistant
